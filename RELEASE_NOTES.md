## muzik 0.3.0 — «Волна»

Плеер для музыки в памяти телефона плюс бесконечный поток треков из интернета.

### Новое
- **«Волна»** — бесконечный поток музыки. Треки подбираются из SoundCloud, YouTube и VK, следующие порции докачиваются автоматически, локальные файлы подмешиваются в очередь.
- **Лайк / дизлайк** прямо на экране «Волны»: лайк уточняет подбор, дизлайк исключает трек и переключает дальше. Кнопка «Сбросить предпочтения» очищает историю.
- **Отдельная вкладка «Волна»** в нижней навигации: текущий трек, прогресс, обложка, список «Дальше в волне» и понятные сообщения об ошибках источников.
- **Настройки «Волны»**: включение источников (SoundCloud / YouTube / VK), адрес сервера Invidious или Piped для YouTube, личный VK access token, сброс предпочтений.

### Изменения
- В плеере для сетевых треков показывается источник, а «В избранное» и «В плейлист» скрыты — эти действия доступны только для локальных файлов.
- Добавлен модуль `media3-exoplayer-hls` для HLS-потоков SoundCloud.

### Источники «Волны» — важное
SoundCloud, YouTube и VK **не предоставляют официального API** для такого воспроизведения. Приложение использует открытые (недокументированные) точки входа этих сервисов:
- они могут перестать работать в любой момент;
- условия площадок могут запрещать подобное использование;
- YouTube работает через указанный вами сервер Invidious/Piped, VK — через ваш личный токен.

Источники можно отключать в настройках, а ошибки каждого из них показываются в интерфейсе как есть.

### Установка
1. Скачайте `.apk` из раздела Assets ниже.
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. При первом запуске выдайте доступ к музыке («Все аудиофайлы»), иначе библиотека будет пустой.

### Технические детали
- Kotlin 2.0, Jetpack Compose, Material 3, Navigation Compose
- Media3 ExoPlayer + MediaSessionService (фоновое воспроизведение), HLS
- Room (медиатека, избранное, плейлисты), DataStore (настройки и предпочтения «Волны»)
- minSdk 26, targetSdk 35
- APK подписан debug-ключом CI — для личного использования, не для публикации в Google Play

Собрано автоматически в GitHub Actions из соответствующего тега.
