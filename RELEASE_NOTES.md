## muzik — локальный музыкальный плеер

Плеер для музыки, которая уже лежит в памяти телефона. Без интернета, без аккаунтов, без рекламы.

### Возможности
- **Медиатека** — автоматическое сканирование музыки через MediaStore (песни, альбомы, исполнители, папки).
- **Плейлисты** — создание, добавление треков, переименование и удаление.
- **Избранное** — лайки сохраняются в локальной базе и не теряются при повторном сканировании.
- **Поиск** по трекам, альбомам и исполнителям.
- **Воспроизведение в фоне** — Media3/ExoPlayer, `MediaSessionService`, управление из уведомления и с экрана блокировки.
- **Liquid Glass UI** — размытые стеклянные панели и орбы (blur на Android 12+, градиентный fallback ниже), Material 3, светлая/тёмная/системная тема.
- **Настройки** — тема, акцентный цвет, поведение при запуске, повторное сканирование медиатеки.

### Установка
1. Скачайте `.apk` из раздела Assets ниже.
2. Откройте файл на телефоне и разрешите установку из этого источника.
3. При первом запуске выдайте доступ к музыке («Все аудиофайлы»), иначе библиотека будет пустой.

### Технические детали
- Kotlin 2.0, Jetpack Compose, Material 3, Navigation Compose
- Media3 ExoPlayer + MediaSessionService (фоновое воспроизведение)
- Room (медиатека, избранное, плейлисты), DataStore (настройки)
- minSdk 26, targetSdk 35
- APK подписан debug-ключом CI — для личного использования, не для публикации в Google Play

Собрано автоматически в GitHub Actions из соответствующего тега.
